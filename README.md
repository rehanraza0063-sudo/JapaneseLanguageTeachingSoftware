# JapaneseLanguageTeachingSoftware

# 🇯🇵 Japanese Language Learning Web Apps

A collection of interactive **Japanese language learning web applications** built with **Python, Flask, HTML, CSS, and JavaScript**.

This project was created to combine my interest in **Japanese language learning** with my software development skills. It includes learning tools for Hiragana, Katakana, Kanji, vocabulary, numbers, greetings, Kanji stroke order, and JLPT preparation from **N5 to N1**.

---

## 📌 Project Overview

The Japanese Language Learning Web Apps project contains multiple independent Flask applications, each designed for a specific area of Japanese language learning.

The applications are beginner-friendly and provide an interactive way to learn, practice, and test Japanese language knowledge.
